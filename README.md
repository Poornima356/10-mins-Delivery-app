Project Title

Zepto Clone – Grocery Delivery Web Application

Key Highlights
Developed a responsive grocery delivery application using HTML5, CSS3, and JavaScript (ES6).
Implemented core JavaScript concepts including DOM Manipulation, Event Handling, Fetch API, Async/Await, Local Storage, Array Methods (map, filter, find), and Modular JavaScript.
Built features such as dynamic product listing, category filtering, search, shopping cart, wishlist, and order management.
Integrated the Geolocation API to fetch and display the user's current delivery location.
Designed a fully responsive UI using Flexbox, CSS Grid, and Media Queries for seamless user experience across devices.
